❓ How to Use Admin Panel

📬 View Customer Messages

  1. Go to the Messages tab
  2. View all customer messages from your website's contact form
  3. See sender name, email, phone, and message text
  4. Delete messages after reading
  5. Export messages as JSON backup

✏️ Edit Website Content

  1. Go to the Website tab
  2. Edit any section (Business Info, Hero, Pricing, etc.)
  3. Manage your flavors - add, edit, or delete
  4. Add social media links
  5. Click "Save All Changes" when done

📏 Edit Product Sizes (OZ)

  1. In the Website tab, find the "Pricing & Sizes" section
  2. Scroll to "📏 Product Sizes (OZ)"
  3. Enter your medium size (e.g., 12 for 12 oz)
  4. Enter your large size (e.g., 16 for 16 oz)
  5. Click "Save All Changes"
  6. Your gallery will now show the custom sizes! (e.g., "12 oz & 16 oz Available")
